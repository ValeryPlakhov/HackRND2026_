Короткий путь от запуска Studio до изменения, которое можно проверить и передать на review.

01 / Полная локальная версия

Нужен JDK 21+. Откройте start-local.cmd либо выполните: 

.\start.ps1 -TrustedLocal
# Затем http://localhost:8080

Linux/macOS: BLUEPRINTS_RUNNER=local sh start.sh. Приложение работает без npm, Maven и ключей API. Python и Node нужны только разработчику для тестов.

Trusted local запускает Java с вашими правами. Используйте доверенные исходники. Docker runner подготовлен, но в этой среде не проверен.

02 / От модели к проверке

  1. Откройте Monolith / 1K и метод countPairs. Canvas связывает AST-узлы с исходными строками.
  2. Рефакторинг и diff → Просмотреть патч. Изучите before/after, причину применимости и допущения.
  3. Применить и проверить. Обе версии отдельно компилируются и исполняются. Успех относится к указанным входам.
  4. Test Lab → Бенчмарк. Укажите countPairs и размеры массива. Сравните samples и медианы.
  5. Mutation покажет, какие изменения замечает набор тестов. Invalid mutants не участвуют в score.
  6. Для FAIL откройте Контрпример. Протокол reducer: n, затем n целых чисел.
  7. Сохраните checkpoint, выделите независимый static-метод в helper, повторите gate и скачайте Evidence ZIP.

03 / Инструменты инженера

Живой canvas

Pan, zoom, minimap, поиск узлов, source location, структурные пути. Двойной клик открывает редактирование поддерживаемого узла.

План с source hash

Пять семейств rewrite. Сервер отклоняет устаревшие и пересекающиеся планы; после правки старый gate теряет силу.

Архитектура и данные

Вызовы, SCC, hotspots, fan-in/out, lexical def/use, доминаторы и объяснимая сложность.

Переносимый review

ZIP с обеими версиями, stdin, patch, manifest и автономным HTML. Диагностика SARIF; граф SVG, Mermaid, DOT.

04 / Клавиши

Команда Действие
Ctrl / ⌘ + K Поиск действий, файлов, методов и правил
Ctrl / ⌘ + Enter Запуск quality gate
Ctrl / ⌘ + S Checkpoint
F в графе Вписать граф в окно
Escape Закрыть диалог

Поиск поддерживает file:Main.java method:count severity:warning rule:BP101 line:5-20. История сохраняется в браузере; серверные jobs живут до рестарта.

05 / Что означает зелёный статус

Raw bytes stdout и stderr, а также exitCode совпали на выбранных stdin. Compile error, timeout и output flood не могут дать PASS. Хеши привязывают отчёт к содержимому исходников.

Конечные тесты не доказывают все входы. SHA-256 не цифровая подпись. Mutation score не coverage. Benchmark harness не JMH. Статические Big O, call graph и data flow имеют допущения; exception flow структурный.

06 / Проверка сборки

python tests/verify.py
# 108 unit + 22 API + 36 Studio API = 166 tests
python tests/source_audit.py

Verify сам поднимает отдельный сервер на loopback:18080 и останавливает после тестов. Нужны JDK21, Node22+, Python3.10+. Подробные отчёты включены в архив.

Статическое демо содержит помеченные записи настоящих прогонов трёх примеров. JVM там нет; для произвольного Java используйте локальную версию.
