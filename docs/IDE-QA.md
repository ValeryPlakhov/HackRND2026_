# Проверка интерфейса IDE 3

Локальный браузерный предпросмотр, Windows, проверка размера окна приложения 1440×900 и стандартного небольшого sidebar preview. Исполняемая сборка проверяется отдельно настоящим Electron smoke test. Native UI automation в среде недоступна, поэтому системный picker не прокликан автоматически.

| Сценарий | Наблюдаемый результат |
|---|---|
| Открытие примера | src/Main.java и Pricing.java видны в дереве и вкладках |
| Метод → граф | total показывает переменную, foreach, операцию и return; withDiscount показывает ветвление |
| Совместный вид | Код и блупринт доступны одновременно; выбранный метод сохраняется |
| Описание блока | Условие объяснено обычными словами, доступны переход к строке и изменение |
| Неверная правка | `(amount >= )` отклонена javac parser; исходник остался прежним |
| Корректная правка | `(amount >= 3000)` появилась в Java и графе; вкладка отмечена несохранённой |
| Сохранение + запуск | Main выполнился в JVM, stdout: сумма 2650, к оплате 2650, exit 0 |
| История | Diff показал 2000 → 3000; восстановление вернуло порог 2000 в редактор |
| Поиск проекта | Pricing найден в Main.java, Pricing.java и README; совпадение открыло Main на нужной строке |
| Изменение после запуска | Старый вывод помечен устаревшим; новый запуск вернул 2650 вместо 2385 |
| Языки | Java доступна, остальные восемь языков — Coming soon |
| Настройки | Тёмная тема и режим «Код и блупринт» применились; светлая тема восстановлена |

Скриншоты: `assets/ide-run.png`, `ide-languages.png`, `ide-dark.png`, `ide-overview.png`. Они показывают веб-предпросмотр того же renderer; нативная работа с папкой реализована в Electron main.

Автоматические тесты дополняют UI-проверку: rooted paths и junction, stale workspace, конфликт сохранения, BOM/CRLF, история, literal search, Git status parser, Java diagnostics, отмена выбора папки и закрывающие скобки. Семь runtime-проверок используют комплектный jlink runtime и настоящий javac/JVM, включая путь с кириллицей и пробелами.

Последняя проверка console: ошибок и предупреждений не обнаружено. Smoke-тест дополнительно сохраняет реальный SVG через Electron download pipeline; в обычном приложении используется системный диалог сохранения.
