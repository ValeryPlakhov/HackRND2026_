# Ответ на независимый аудит (версия 4.2.0)

Независимый аудит версии 4.1.0 нашёл 26 замечаний (FINDINGS F01–F26). Ниже указано, что исправлено в 4.2.0, каким тестом закреплено и что осталось известным ограничением. Каждый контрпример из аудита превращён в регрессионный тест:

- `tests/test_audit_regressions.py` — 20 тестов на настоящем `javac` и JVM (F06–F12);
- `tests/unit/audit.test.mjs` — 9 тестов интерфейса (F01, F02, F05, F18, F19).

Оба набора входят в `python tests/verify.py`; результат лежит в `docs/verification-summary.json` (ключ `auditRegressions`).

## Исправлено

Получатель вызова с приоритетом ниже постфиксного (тернарный, приведение) тоже получает скобки | `audit.test.mjs`, круговые пробы `tests/blueprint_roundtrip.mjs` |

| F04 | Ответ декомпозиции перезаписывает правки, сделанные во время запроса | Декомпозиция запоминает проект и сравнивает исходники перед записью. Если файл успел измениться, результат не применяется. Если создать новый файл не удалось, правка откатывается | ручная проверка в IDE |

Анализ утечек учитывает позицию: захват лямбдой или передача в метод до последней проверки запрещает план | `test_audit_regressions.py` |
| F08 | Сгенерированные имена сталкиваются с исходными | Свежее имя ищется по границам слова, служебные имена (`bpFrequency` и др.) всегда проверяются на конфликт | `test_audit_regressions.py` |
| F09 | Компилируемая декомпозиция меняет привязку имён | Метод не переносится, если имя одновременно поле класса и локальная переменная, или если класс наследуется, а метод использует неразрешённые имена. Сигнатура квалифицируется так же, как тело. Старый `/api/extract` идёт через ту же декомпозицию | `test_audit_regressions.py` |
| F10 | Сравнение stderr пропускает реальные различия | Политика сравнения: stdout побайтно, stderr побайтно без строк кадров стека JVM (`\tat …(File.java:N)`, `... N more`), код завершения и флаг запуска. Обычный текст в stderr сравнивается полностью | `test_audit_regressions.py` |

| F19 | Типы пинов не обеспечены контрактом | Провод между явно несовместимыми типами не соединяется (расширение примитивов и упаковка разрешены). Граф с неподключёнными входами остаётся черновиком и код не меняет. Вызов с несколькими потребителями помечается предупреждением о повторном вычислении | `audit.test.mjs` |

## Известные ограничения (не исправлены в 4.2.0)

| ID | Замечание | Текущее состояние |
|---|---|---|
| F13 | CFG некорректно описывает `finally`, `break`/`continue` с метками | Граф потока управления для диагностики — приближение. Блок-редактор хранит такие конструкции узлом «Java» с исходным текстом |
| F14 | Big O выдаёт необоснованные оценки | Оценка структурная, по вложенности циклов в AST. Вызовы других методов и рекурсия не учитываются. Окончательное слово за проверкой поведения |
| F15 | Def-use объединяет разные переменные с одним именем | Панель переменных группирует по имени в пределах метода, без учёта вложенных областей видимости |
| F16 | `valid` означает только синтаксис | Поле `valid` в ответе `/api/analyze` означает «разобрано парсером без синтаксических ошибок». Компиляция проверяется отдельно, при запуске и проверке поведения |
| F17 | Поддержка Java при исполнении шире, чем в блупринте | Исполняется любой Java 21 код. В блупринте конструкции без своего узла (switch, try, лямбды, локальные классы) показаны узлом «Java» и редактируются текстом |
| F21, F22 | Исполнение не изолировано, лимиты в разных механизмах | Локальный запуск идёт с правами пользователя с лимитами времени, памяти и вывода. Это не песочница, открывайте только доверенный код. Docker-режим даёт изоляцию, но в этом релизе не тестировался вживую |
| F23 | Тестовая база не закрывала классы ошибок | Частично закрыто регрессиями выше. Генеративные тесты для кодогенерации пока не добавлены |
| F26 | Ограничения путей и размеров различаются между слоями | Без изменений |

Совпадение поведения на конечном наборе входов — свидетельство, а не доказательство эквивалентности на всех данных.
