# Проверка доработки Web UX

Дата: 25.10.2026. База: `fcf2330`, ветка `web-usability`.

## Автоматические проверки

Полный `tests/verify.py` запускался в отдельной копии проекта с переносимым Temurin JDK 21, Node 24.16.0 и Python 3.12.14. Результат: **261/261**, 247,09 секунды.

| Часть | Результат |
|---|---|
| Node unit tests | 156/156 |
| Engine API | 23/23 |
| Studio API | 36/36 |
| IDE API | 17/17 |
| Blueprint roundtrip: проекты и probes | 9/9 |
| Audit regressions | 20/20 |

После финальных изменений текста, панелей и отображения состояния повторно пройдены все 156 Node unit tests. `git diff --check` не обнаружил ошибок пробелов. Java backend в этой доработке не изменялся. Полный прогон использовал локальное исполнение; облачное production-развёртывание и Docker daemon этим прогоном не проверены.

Добавлены восемь регрессионных проверок: оформление портов не меняет Java; читаемые подписи управления; обучение не заменяет открытый проект; исправление открывает preview; запрещено применение без входов или поверх ожидающего исправления; вкладки обновляют видимую страницу; preview показывает включённые случаи; отказ среды не называется регрессией программы.

## Проверено в браузере

- Первый вход показывает выбор новичок / опытный; после выбора окно не повторяется при обычном обновлении.
- Обучение повторно запускается из группы «Помощь», все шесть шагов достижимы.
- Группы действий раскрывают соответствующий набор команд.
- Обзор проекта показывает три основных сценария; подробности раскрываются отдельно.
- Задача частотного индекса открывает причину, diff и шесть включённых входов до применения.
- Применение запускает реальную компиляцию и сравнение: **6/6 совпавших входов** учебного магазина.
- Откат возвращает код к исходной версии, помечая прошлый отчёт устаревшим.
- Вкладки входов и результата переключают видимую страницу; добавлен, назван, заполнен и удалён временный седьмой случай.
- В редакторе блоков открывается настройка портов; подпись параметра изменена без изменения Java и без появления несохранённых правок исходника.
- Раскладка «Схема» и режим фокуса освобождают область от кода и файловой панели.

Визуально проверено окно 1280×720. Media queries для узких экранов добавлены, но аппаратное мобильное тестирование и исследование удобства с внешними пользователями не выполнялись.

## Повторение

```powershell
# Нужны существующие JDK 21+, Node и Python.
python tests/verify.py
node --test tests/unit/*.test.mjs
.\start.ps1 -TrustedLocal -Port 18082
```

Полный скрипт генерирует отчёты в `docs/`, поэтому для независимой проверки без изменения сохранённых отчётов использовалась отдельная копия. Лог и сводка текущего прогона сохранены вне репозитория: `C:/Hakaton/web-usability-review/verification.log` и `verification-summary.json`. Снимок первого входа: `C:/Hakaton/web-usability-review/onboarding.png`.
