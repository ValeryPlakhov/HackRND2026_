# Ручная проверка в браузере

## Новый основной конструктор

Проверено создание с чистого листа без ввода Java: Спросить «Цена» (250) → Посчитать ×2 с именем «За два товара» → Показать «К оплате: » + результат. Реальная JVM вернула «К оплате: 500». Проверены поля, выбор значений из предыдущих шагов и сохранение настроек при смене оператора.

Также проверены выбор готовых примеров, настройка сообщения, изменение порога условия, оба исхода ветвления, форма запуска и подпись «Выполнено на Java». Схема приветствия упрощена до двух блоков, код и метрики отсутствуют на первом экране. Скриншоты: assets/builder-overview.png, builder-run.png, builder-templates.png. Публикация не выполняется по выбору владельца.
